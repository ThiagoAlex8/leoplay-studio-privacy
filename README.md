Leo Dinoland pages are generated from the same source as the bundled offline policy in the app. Update the policy source in the private app repository and use its `scripts/generate-privacy.mjs` generator; do not edit generated HTML independently.

This repository contains only privacy pages and this documentation, not game source code or assets. No trackers, analytics, remote fonts or JavaScript are included in these pages. The repository root `index.html` remains the existing Leo Play&Learn policy; do not replace it with an app directory.
